Adapted 2026-08-12 by the pilot lead (with Claude) into a take-home worksheet from Unit 2, Activity 9 (“The Model Comparison”), with concrete steps for BoodleBox’s model picker. Grading policy and which models to compare are both left to instructor discretion — the pairings below are examples, not a requirement. See the working repo’s decision log, 2026-08-12.

The Concept

AI capability varies meaningfully across models, not just across “AI vs. no AI” or “grounded vs. ungrounded.” Students run the identical reasoning-heavy prompt through two different BoodleBox models and compare the results directly — the same logic used to compare two raters or instruments on the same item.

Psychology objectiveCapability calibration across AI models — extending the Unit 1 mental model (trained model + context + tools → response) with a fourth variable: which trained model.
AI competencyModel-selection judgment and cross-model capability calibration.
TierLiteracy
Time~30–40 min core comparison. +15 min for the optional sycophancy extension.
Human-only componentA prediction before running the comparison, and the written judgment of which response was actually stronger — not delegated to a third AI asked to “judge” the two outputs.
Verification requirementAny factual claim a student intends to reuse is checked against course material or a credible source, regardless of which model produced it.

Step 1: Pick Your Prompt

Choose something that requires reasoning, not lookup — a case analysis, a multi-step problem, an argument to evaluate. A simple factual question won’t show a capability gap; both models will likely just answer it correctly. Write the prompt down before starting.

Step 2: Predict

Before running anything, write one sentence: which model do you expect to do better on this prompt, and why?

Step 3: Pick Two Models to Compare

In BoodleBox, click the bot avatar in the chat bar — or type @ — to browse available models. Pick two. Some ideas, not a requirement:

  • A top-tier reasoning model (BoodleBox currently includes access to Claude Opus 4.7) against a faster, lighter default model.
  • Two different underlying AI providers, if BoodleBox’s roster includes more than one.
  • The model you’d default to without thinking about it, against one you’ve never tried.

Step 4: Run the Same Prompt in Two Separate Chats

Start a new chat for each model — don’t switch models mid-conversation using Bot Stack for this activity. Switching models inside the same chat lets the second model see the first model’s answer already sitting in the conversation, which contaminates the comparison (the same context-conditioning effect from Unit 1’s Next Word Game). Two clean, separate chats keep the comparison fair. Paste the identical prompt into both and save both full responses.

Step 5: Compare

For each response, rate and note:

  • Response quality — is the reasoning actually sound, or just confidently stated?
  • Reasoning depth — did it engage with the hard part of the problem, or the easy version of it?
  • Error rate — any factual, logical, or arithmetic errors? Check against course material where applicable.
  • Confidence calibration — did it sound equally confident regardless of whether it was actually right?

Step 6 (Optional Extension): Test the Sycophancy Angle

A recent analysis of real AI conversations found that some AI model lines tend to affirm and agree with users more, while others push back and critique more. Pick a claim or opinion you personally hold — something you’d defend. Ask both models to evaluate it honestly. Which one pushed back harder? Which one agreed with you faster?

Connects directly to Unit 2’s Sycophancy activities — if you did The Flattery Trap or The Bad Argument Test earlier in this unit, this is the same test, run across two models instead of one.

Debrief Question

Compare your Step 2 prediction to what you actually found. Were you right? If you were using the weaker model for something academically important — without realizing it was weaker — what would the consequence be, and how would you have known?
